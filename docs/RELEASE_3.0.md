# 3.0.0 发布说明

本版从 2.0 升级章节缓存机制，重点是章节按需获取、独立保存和断点续读。

## 更新内容

- **章节级缓存与边读边下**：打开未缓存的微信读书书籍后进入阅读流程，按章节获取正文和图片，不再要求先完成整本缓存。
- **断点续传**：章节正文、图片与校验信息分开保存；缓存中断后保留已完成章节，后续只补齐缺失内容。
- **阅读交互**：统一章节加载提示与进度反馈；章节尚未就绪时按需等待该章。
- **缓存维护**：支持重新检查和补齐章节资源；本地阅读器继续负责排版、字体、字号、目录和翻页。
- **保留微信读书功能**：书架与封面同步、账号管理、进度双向同步及阅读时长上报。

## 下载文件

此发行版**只提供 16 MiB 全闪存镜像**：

- `kiikoread-metalio47-3.0.0-full-flash-16MB.bin`（16,777,216 字节）
- SHA-256：`798a77a9e92ee7e8168a02d50bfa7a1c83e10c6038fda8b5b0bd310208d72baf`
- 写入偏移：`0x0`

请确认设备为 **Metalio 4.7 V1.5 / ESP32-S31 / 16 MiB 闪存**。全闪存写入会覆盖设备完整闪存，清除 Wi-Fi 配置、微信读书登录态、阅读数据及系统设置；建议先备份 SD 卡上的书籍和数据。不要把该镜像写到 `0x10000`。

源码和分章节缓存设计文档见仓库 `main/book/weread_cache.c`、`docs/WEREAD_CHAPTER_CACHE_DESIGN.md`、`docs/WEREAD_CHAPTER_CACHE_CHANGES.md`。完整刷写步骤见 `docs/FULL_FLASH_16MB.md`。
